Give your agent the kit.

TRUGS-AGENT is the onboarding kit: entry instructions, a primer and examples. TRL is the sentence form of a graph. Compiling and validating its structure does not prove that an agent obeys it.

These commands and expected outputs follow the kit’s README.

Install in your Python environment.

Use Python 3.11 or later. Install the language tools, describe tool and onboarding installer from the Python package index:

python -m pip install --quiet "trugs-tools>=2.4.0,<3" trugs-web==2.1.0 trugs-agent==2.0.0

Expected stdout: empty; exit status 0.

Check the installed version:

trugs-agent --version

Expected stdout: trugs-agent 2.0.0; exit status 0.

trugs-agent package page

In your agent’s project.

Run the installer from your project directory. It lists every destination before writing. Existing files require a terminal and an explicit yes.

trugs-agent install

It lists AGENTS.md, CLAUDE.md, the Cursor rule and plugin manifest, then prints PASS: trugs-agent check on success (status 0).

Run the check explicitly:

trugs-agent check

Expected stdout: PASS: trugs-agent check; exit status 0.

Read the entry, then the primer.

Have your agent read the installed AGENTS.md, then PRIMER.md. The primer explains the graph, vocabulary and validation loop. Return to the TRUGS-AGENT repository for examples and the map.
